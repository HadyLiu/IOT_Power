# 用户手册

> 适用于 IOT_Power 上位机（控制 DC3005U 可编程电源 / 功耗分析仪）。功能编号见 [PRD.md](PRD.md)。

## 1. 简介
本软件通过 USB 连接 DC3005U，实时显示电压、电流（可到 µA 级）、功率，可设定输出电压（0.8~24 V，1 mV 步进）和限流（输出电流上限，0.5~5.0 A，1 mA 步进），并可自定义更窄的安全边界、开关输出、绘制曲线并录制数据。支持 Windows 10/11 与 Ubuntu 22.04 及以上。

## 2. 安装
- **Windows**：运行 `IOT_Power-Setup-X.Y.Z.exe` 按提示安装；或解压便携版 zip 直接运行 `iot-power.exe`。
- **Linux（Ubuntu）**：
  ```bash
  sudo apt install ./iot-power_X.Y.Z-1_amd64.deb
  ```
  安装后在应用菜单中打开「IOT_Power」，或终端运行 `iot-power`。

## 3. 驱动与权限
- **Windows**：设备需使用 WinUSB 驱动。装过官方 IoT Power 软件的电脑一般已就绪，设备管理器中可见「DC3005U WinUSB」。
- **Linux**：.deb 已安装 udev 规则；若用的是便携版，手动执行：
  ```bash
  echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="0408", ATTR{idProduct}=="1043", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/99-dc3005u.rules
  sudo udevadm control --reload-rules && sudo udevadm trigger
  ```
  然后重新插拔设备。

## 4. 连接设备
1. 用 USB 线连接 DC3005U 与电脑。
2. **关闭官方 IoT Power 软件**（设备同一时间只能被一个程序使用）。
3. 点击左下角「连接」。成功后状态灯变绿，显示型号、序列号和固件版本，状态区开始刷新。**为安全起见，每次手动连接或程序启动后的首次连接，软件会先关闭一次设备输出**，需要输出时再手动点 ON。
4. USB 断开后软件会自动重连。**自动重连不会关闭输出**（避免 USB 抖动打断长时间测试），录制也不会中断；断线期间界面显示红色横幅，输出按钮保持断线前状态并加黄框「状态未经设备确认」，请留意设备实际状态。唯一例外：如果你在断线前点了 OFF 但没成功，或在重连期间点了 OFF，重连后软件会立即关闭输出。点「断开」释放设备。
5. 启用「启动时自动连接」时，如果设备还没插上，软件会显示「等待设备…」，插上后自动连接。软件只连接第一台 DC3005U；换了一台设备时会提示序列号与上次不同。

## 5. 设定输出
1. 在「输出设定」输入设定电压和限流（只能输入数字和小数点），回车或离开输入框即生效。点进输入框时旁边会显示允许范围，也就是当前「安全边界」（默认等于硬件极限 0.8~24 V / 0.5~5.0 A，设定框下方也有一行小字）。**超出范围时输入框变红、不会下发**，请改成范围内的值。
   「限流」是允许流过的最大电流，不是测到的电流。它的下限是 0.5 A，但被测设备只取 µA 级电流时照样能测得到。
   提交后输入框旁会出现小转圈，设备回显确认后消失；如果设备没应答或没生效，输入框会恢复成设备当前的设定并提示「设定未生效」。
   输入框下方的「设备 x V / y A」是设备当前真正的设定。输入框里改了但还没提交时，旁边显示「未提交」；这时即使设备设定变了（比如在设备面板上改了），软件也不会覆盖你正在改的值，只会提示。没连接时改的值，连接后也不会自动下发。
2. 勾选「快速设定」后，修改数值立即生效。
3. 点击「- OFF -」按钮打开输出，变为「- ON -」；再点关闭。点 ON 时如果输入框里的值还没提交，软件会先下发并确认设定，再打开输出；设定没生效就不会打开输出。
   设备读不回开关状态，所以按钮有三种样子：正常颜色表示命令已被设备应答；黄框「状态未经设备确认」表示断线重连后还没再操作过；红色「未知」表示不知道设备是否在输出（关闭了「首次连接时关闭输出」，或关闭失败），这时点按钮会关闭输出。打开失败时按钮保持 OFF；关闭失败时显示「未知」，软件每秒继续重试，并提示你手动关闭设备输出。
4. 在「电源设置」中可开启「输出开启警告」（开输出前确认）和「输出时锁定参数」（输出期间禁止改设定）。

> 提示：设定换算已确定（电压按 mV、限流按 mA 下发），首次使用仍建议用万用表核对一次。

## 6. 曲线、录制与辅助功能
- **状态区**：电压、电流由设备测得，电流会自动切换 A / mA / µA 显示；功率 = 电压 × 电流；能量、平均功率、负载阻值由软件计算（电流为 0 时阻值显示 ∞，阻值大于 10 MΩ 显示 --），点曲线工具栏上的「回零」清零。断线期间不计能量。注意：软件每次轮询（默认 50 ms）只取一个读数，比这更短的电流脉冲可能漏掉，能量是估算值。
- **曲线**：上下两个图分别选择显示电压/电流/功率/阻值；「采样间隔」（即轮询间隔，最小 50 ms）决定采样快慢，右侧显示实际采样率。「适应」自动缩放，「保持」暂停画面，「清空」清除数据，底部滑块可回看历史，信息栏显示最大/最小/平均值。
- **录制**：点「录制」开始，同时生成 `record_日期_时间.txt`（采集日志，见第 7 节）和同名 `.csv`（列：`time/s,voltage/V,current/A,power/W,seq`，电流和功率保留 8 位小数，即 10 nA 分辨率；每 30 秒自动保存；可在图形设置关闭 CSV）。再点停止，可打开文件所在目录。「导出」把当前缓冲区数据另存为 CSV。
- **悬浮窗**：点「浮窗」打开置顶小窗显示 U/I/P。
- **预设组**：在辅助功能「预设组」页选择 1~9 即应用对应电压和限流；可修改后保存。
- **序列执行**：添加「延迟 / 等待到时刻 / 设电压 / 设限流」步骤，单次或循环运行；`SET-V 0` 表示关闭输出。可保存为 txt。
- **高级功能**（后续版本）：功率闭环、直流扫描、函数发生器、电池模拟。这些由软件反复修改设定实现，变化速度有限；同一时间只能运行一个；窗口最小化也会继续运行。运行中按 **Esc**（任何窗口都有效）、页面上的「急停」或输出按钮 OFF，会立即停止并关闭输出。没有高级功能在运行时，Esc 只关闭对话框，不会动输出。开启「输出时锁定参数」时，输出打开后不能再启动高级功能，但输出关闭时已启动的功能会正常运行。电池模拟在低电量时电压不会低于安全边界下限，曲线末段会被削平。

## 7. 采集日志（txt）与记录分析
- **采集日志**：每次录制都会生成一个 txt。开头几行以 `#` 开始，写着软件版本、设备序列号、开始时间、采样间隔、安全边界和列说明；之后每行一个样本，用制表符分隔：时间、电压、电流、功率、输出状态、设定电压、限流、帧序号；以 `!` 开头的是事件行（改设定、开关输出、断线/重连、命令失败、急停等）。用记事本或 Excel 都能打开。
  ```text
  # columns=t_s	v_V	i_A	p_W	out	vset_V	iset_A	seq
  0.000000	5.001	0.57512345	2.87619237	1	5.000	2.000	1203456
  !30.000000	LINK	state=lost
  ```
- **写盘与分文件**：每 1 秒写一次盘，程序崩溃或断电最多丢最后约 1 秒；默认每 60 分钟或 100 MB 自动换一个文件（`_part2`、`_part3`…）。目录默认是「文档/IOT_Power」，可在图形设置里改；也可设置「连接后自动开始录制」。
- **分析**：点曲线工具栏的「分析」，或把 txt 拖到主窗口，打开分析窗口：可以浏览和回放曲线，拖选一段时间，查看最大/最小/平均/RMS、能量（Wh）、容量（mAh）、时长；事件在曲线上用竖线标出，点事件列表可跳过去；断线时段不计入能量。选中的区间可导出为 CSV。多文件对比在后续版本提供。

## 8. 设置
- **电源设置**：采样（轮询）间隔、读写/应答超时、启动自动连接、首次连接时关闭输出（默认开启，重连不主动关）、输出开启警告、输出时锁定参数、**安全边界**，以及远程接口（默认关闭；开启后状态栏显示「远程控制中」；「允许远程打开输出」需单独勾选，远程开输出不会弹确认框）。
- **安全边界**：硬件极限 0.8~24 V、0.5~5.0 A 是设备固定的，不能改；安全边界是你在这个范围内自己设的工作范围（电压下限/上限、限流下限/上限），默认等于硬件极限，点「恢复硬件极限」还原。每个值必须在硬件极限内且下限不大于上限，填错的框会变红并说明原因，此时无法确定保存。**只能在输出关闭时修改**（输出状态「未知」时也不能改，请先点按钮关闭输出）。设好后：手动输入、预设、序列、扫描/功率闭环/函数发生器/电池模拟的参数（以及 HTTP 接口）超出边界都会被**拒绝**并提示允许范围；预设和序列里超出边界的项显示为红色，选这个预设会被拒绝，序列执行到这一行默认停止（可在电源设置改为跳过）；高级功能有参数超界时不能启动。功率闭环、函数发生器、电池模拟运行中算出来的瞬时值超界时会被限制在边界内，并在状态栏提示。把边界改窄后，如果当前设定值已经超出新边界，软件会提示你调整，调整好之前不能打开输出。
- **图形设置**：主题（暗黑/明亮/自定义）、语言（中文/English）、刷新率、记录点数、小数位、置零阈值（电流默认 0 即不置零，便于测 µA 级电流）、电流单位（自动/A/mA/µA）、显示修正（y=kx+b）、录制（目录、同时保存 CSV、自动开始、分文件）。电流显示分辨率 10 nA，实际精度以设备规格为准。
- 设置自动保存在 Windows `%APPDATA%\IOT_Power\settings.json`、Linux `~/.config/iot_power/settings.json`，删除该文件即恢复默认。

## 9. 常见问题
| 问题 | 解决方法 |
|---|---|
| 提示“设备被占用 / 无法打开接口” | 关闭官方 IoT Power 软件（包括托盘里的进程）后重新点击「连接」 |
| Windows 提示“未找到设备” | 检查 USB 线；打开**设备管理器**，若「DC3005U WinUSB」带向下箭头（已禁用），右键选择「启用设备」后重试；若显示黄色感叹号则需安装 WinUSB 驱动 |
| Linux 提示“权限不足” | 按第 3 节安装 udev 规则并重新插拔；或检查是否在容器/Snap 沙箱中运行 |
| 中文显示为方框 | 软件内置中文字体，若仍异常请在图形设置切换语言后重启，并反馈版本号 |
| 读数不刷新 / 频繁重连 | 换短一些的 USB 线或直连主板接口；适当增大轮询间隔 |
| 设定值输入框变红 / 预设选不了 / 高级功能不能启动 | 值超出了安全边界：改成提示的允许范围内，或关闭输出后在电源设置里放宽安全边界（最大到硬件极限） |
| 小电流显示为 0 | 检查图形设置里电流置零阈值是否被改大（默认 0） |
| 设定值与实际输出有偏差 | 换算已按 mV/mA 确定；小偏差属设备精度范围，可在图形设置中启用显示修正（修正后的下发值超出 0.8~24 V / 0.5~5.0 A 时会被拒绝） |
| 输入框旁显示「未提交」 | 你改的值还没下发：按回车或点别处提交，或直接点 ON（会先下发再开输出） |
| 提示「设定未生效」/「打开输出失败」 | 设备没有应答或回显不一致，检查 USB 线；可在电源设置查看命令统计、适当加大应答超时 |
| 断线后设备还在输出 | 自动重连不会关输出；如需关闭请在设备上关闭；重连期间也可以点 OFF，软件会在重连成功后立即关输出 |
| 录制文件在哪 | 停止录制时弹窗可点「打开文件路径」，默认在「文档/IOT_Power」，可在图形设置的录制目录里修改 |
