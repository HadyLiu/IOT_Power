## 2. 面板说明
### 2.1 状态区（F02）
- 8 个大号等宽数字，2 行 × 4 列；V/I 来自设备，功率由主机计算 V̄×Ī（设备回报功率不显示，仅作调试校验），平均功率/平均电流/负载阻值/能量（J，≥1000 J 显示 kJ）/电量（mAh，≥1000 mAh 显示 Ah）由上位机积分或计算。
- 平均功率、平均电流只统计本次输出开启以来的时段，输出关闭时为 0；曲线「保持」时平均值、能量、电量冻结显示。
- 刷新率默认 10 fps，显示两次刷新间样本平均；小数位 = 3 + 插值位数（0~3）。
- 曲线工具栏的「清空」（确认后）同时清零能量、电量与平均值；不再单独设「回零」按钮。
- 电流自动量程：≥1 A 显示 A，1 mA~1 A 显示 mA，<1 mA 显示 µA（标签里的单位跟着变，5% 回差）；功率同样 W/mW/µW。可在图形设置固定单位。设备分辨率 10 nA。
- 阻值：I = 0 显示「∞」，R > 10 MΩ 显示「--」，其余 Ω/kΩ/MΩ 自动量程。电流置零阈值默认 0（关闭）。规则详见 [详细设计.md](详细设计.md#36-小电流显示与功率阻值规则)。
### 2.2 输出设定（F03）
- ON/OFF 大按钮，颜色随状态（见配色 on/off）。点 ON：若设定框的编辑值与设备设定不同，先下发 `0x03` 并等回显确认，再发 `0x06 01`；OFF 下发 `0x06 00`。AUX 运行中只有 OFF 可点，等同急停。
- 设定电压、限流（输出电流上限，与测量电流不是一回事）：只允许输入数字和小数点，框内带单位后缀（V / A）；获得焦点时旁边浮出「允许范围 {min}~{max} {unit}」（当前安全边界）。超出范围时输入框标红、显示允许范围、**不下发**（不自动改值）；回车或离开输入框且合法才提交；「快速设定」时值变即提交（节流 ≥100 ms）。
- 设定框下方一行小字「设备 12.000V / 2.000A」显示设备设定；编辑值与设备设定不同时框旁显示「未提交」。设备回显变了而你的编辑还没提交时，编辑值不被覆盖，只提示「设备设定已变为 …，你的编辑未提交」。规则见 [详细设计 §2.6](详细设计.md#26-设定值模型编辑值与设备设定)。
- 进度条显示实测/设定比例。
- 再下一行小字显示当前安全边界（`safety_summary`），边界比硬件极限窄时用黄色；悬停 ⓘ 显示完整说明，点击打开电源设置的安全边界区。
- 设备当前输出状态无法从读数帧确认（[PRD §8](PRD.md#8-待确认) #3），按钮按三级可信度显示：**已应答**（本次连接内最后一条 `0x06` 已应答）正常颜色 + 灰色 ⓘ；**未经确认**（重连后还没再发过 `0x06`）保持原值，加黄色边框和「状态未经设备确认」；**未知**（`off_on_connect` 关闭时首次连接后，或关输出失败）红色「未知」，此时点按钮的动作是关输出。ON 未应答时按钮保持 OFF 并提示失败；OFF 未应答时变为「未知」并每 1 s 持续重试。
- 设定提交后框旁显示小转圈，读数回显（@52/@54）一致后消失；失败时编辑值恢复为设备设定并 toast「设定未生效」。
### 2.3 数据波形（F04/F05）
- 两个 `egui_plot::Plot`，下拉选择电压/电流/功率/阻值/无，X 轴联动。
- 「采样间隔」沿用原版名称（默认 50 ms），实际含义是上位机发送 `0x05` 的轮询间隔，取代原版 `getmsg`；可设范围 50~65535 ms（下限 50 ms，实测后再调）。
- 按钮（原版顺序）：录制/停止、导出、适应/手动、保持/解除、清空（确认，同时清零能量、电量与平均值）、浮窗，以及新增的「分析」。原版的「回零」并入「清空」。统计栏格式 `Vavg/Vmax/Vmin/Vpp`。缓冲默认 100000 点（上限 100 万），最少显示 400 点，曲线刷新上限 50 fps。界面卡顿导致丢弃样本时，缓冲占用旁显示「界面丢弃 N 点」（录制与能量不受影响）。
- 采样率旁 ⓘ 提示「每次轮询只取一个读数，更短的电流脉冲可能漏掉，能量为估算值」。
- 断线时段曲线断开不连线。

## 3. 对话框
### 3.1 电源设置（F08）
原版对话框里的设备功能区已整体删除（DC3005U 无此功能），那块位置改放「安全边界」（F16）。对话框一页，按钮名仍为「电源设置」：
```
┌ 电源设置 ───────────────────────────────────┐
│ - 连接设置 -                                 │
│ 轮询间隔 [  50] ms (≥50)                      │
│ 读写超时 [2000] ms  应答超时 [300]/[500] ms   │
│ □ 启动时自动连接   ☑ 首次连接时关闭输出        │
│ DC3005U  S/N 8B63A8F401E4  FW 1.9.5          │
│ 命令统计：成功 1234 / 超时 0 / 无效 0，平均 4 ms │
│─────────────────────────────────────────────│
│ - 安全边界 -   硬件极限(固定)：0.8~24 V，0.5~5.0 A │
│ 电压下限 [ 0.800] V   电压上限 [24.000] V     │
│ 限流下限 [ 0.500] A   限流上限 [ 5.000] A     │
│ （不合法的框标红，下方显示原因）               │
│ [恢复硬件极限]                                │
│ （输出开启时整块置灰：请先关闭输出再修改安全边界） │
│─────────────────────────────────────────────│
│ 其它设置                                      │
│ □ 输出开启警告    □ 输出时锁定参数            │
│─────────────────────────────────────────────│
│ 远程接口（P2）                                │
│ □ 启用本地 HTTP 接口  端口 [17321]  [复制 token]│
│ □ 允许远程打开输出（默认不勾）                 │
│─────────────────────────────────────────────│
│                         [ 确定 / OK ]         │
└─────────────────────────────────────────────┘
```
- 安全边界校验：四个框只允许数字和小数点（按 0.001 存储）；每个值须在硬件极限内（否则标红并显示如「电压上限须在 0.8~24 V 内」），下限 > 上限时两框标红并显示「电压下限不能大于电压上限」；有任何错误时 [确定] 禁用、不保存。输出可能为开（开的任一可信度或未知）或 AUX 运行时整块置灰并显示提示。
- 改窄边界后，如当前编辑值或设备设定超出新边界：弹窗「当前设定值超出新的安全边界，请调整」，主窗口设定框标红，ON 按钮禁用直到调整好；不自动修改设定值。
- 连接（原「串口号/波特率」位置）：轮询间隔（50~65535 ms）、读写超时、应答超时（命令/轮询）、启动自动连接、首次连接时关闭输出（默认开启；重连不主动关）；显示型号 / 序列号 / 固件版本和命令统计。不提供设备选择（多设备不在范围内，始终连第一台）；序列号与上次不同时提示。
- 其它设置：输出开启警告、输出时锁定参数。
- 远程接口（P2，F14）：默认关闭；开启后状态栏显示「远程控制中」；「允许远程打开输出」单独勾选，默认不勾；远程开输出不弹确认框。
### 3.2 图形设置（F08/F15）
- UI：主题（暗黑/明亮/自定义）、输入方式（按位更改/自由更改，默认自由）、语言（中文/English，新增）。
- 图表：最大刷新率、记录点数、最小显示点数、曲线抗锯齿、曲线降采样（替代原 OpenGL 加速）。
- 状态区：刷新率、插值位数、置零阈值 V/A（电流默认 0，即关闭）、电流单位（自动/A/mA/µA）。
- 录制（F05/F17）：录制目录、同时保存 CSV（默认开）、连接后自动开始录制（默认关）、自动分文件（每 60 分钟或 100 MB）。
- 显示修正：勾选「应用修正参数 (y=kx+b)」；读数 Vk/Vb/Ik/Ib；设定 Vk/Vb/Ik/Ib（纯上位机线性修正；安全边界校验用户输入的值，修正后的下发值再校验硬件极限，见 [详细设计 §5](详细设计.md#5-安全规则) 第 2 条）。
### 3.3 其他窗口
- 悬浮窗（F09）：75×140 px，置顶、无边框、初始透明度 0.95，显示 U/I/P；左键拖动，双击折叠标签（高 80 px），滚轮调透明度 0.1~1.0，右键菜单 折叠/展开/关闭。
- 结果曲线窗（F11/F13）：X/Y 交换（电池曲线禁用）、十字线高亮当前点、多项式拟合次数 0~8（最小二乘 + RMSE，见 [详细设计.md](详细设计.md#46-结果曲线窗rw的拟合)）。
- 记录分析窗口（F17）：见 §3.4。
- 提示框：设备被占用、权限不足、未找到设备，各给出操作建议（文案见 [用户手册.md](用户手册.md#9-常见问题)）。

### 3.4 记录分析窗口（F17）
入口：曲线工具栏「分析」按钮；或把 txt 文件拖到主窗口。独立窗口（`show_viewport_deferred`），不影响设备和实时曲线，可同时开多个。

│ ┌上曲线 [电压▼]───────────────────────────────────────────┐ ┌事件──────────────┐ │
│ │        │SET            ┊LINK lost  ┊restored            │ │12.3 s 设定 5V/1A │ │
│ └─────────────────────────────────────────────────────────┘ │20.1 s 急停 关输出│ │

│ │                                                         │ │31.2 s 重连       │ │

│ │       最大      最小      平均      RMS     │ 能量 0.2620 Wh  容量 52.41 mAh   │ │
│ │ V   5.003     4.998     5.001     5.001     │ 断线时段 1 段，共 1.2 s（不计入） │ │
│ │ I   612.3mA   0.051mA   575.0mA   580.2mA   │                                  │ │

│ └─────────────────────────────────────────────────────────────────────────────┘ │

- 事件在曲线上画竖线（设定=蓝、开关=绿/黄、断线=红、命令失败=橙），悬停显示详情，点击事件列表跳到该时刻。
- 大文件后台解析并显示进度；最后一行不完整时提示「最后一行不完整，已忽略」。
- 多文件对比（P2）：最多 4 个文件叠加，图例区分，可按起点或绝对时间对齐。

## 6. 交互状态
| 状态 | 表现 |
|---|---|
| 未连接 | 状态灯灰；设定可编辑但不下发（连接后也不自动下发，标「未提交」）；ON 按钮禁用；曲线停止 |
| 连接中 | 状态灯黄 + 转圈；启动自动连接找不到设备时显示「等待设备…」并每 1 s 重试 |
| 重连中 | 状态灯黄 + 转圈 + “重连第 n 次”；红色横幅「设备已断开，输出可能仍为开，请检查设备」；输出按钮保持断线前状态并加黄框「状态未经设备确认」；录制继续；输出可能为开时 OFF 仍可点，只记录请求，横幅下显示「已记录关输出请求，重连后立即执行」 |
| 输出未知 | 按钮红色「未知」，点击即关输出；安全边界不可改；退出时按输出为开处理 |
| 已连接 | 状态灯绿，显示型号与序列号 |
| 输出 ON 且锁定 | 设定控件、预设、辅助功能启动禁用（输出关闭时已启动的 AUX 继续运行） |
| 输出 ON | 电源设置里的安全边界区置灰，提示「请先关闭输出再修改安全边界」 |
| 输入超界 | 输入框红框 + 下方红字「允许范围 …」；不下发；ON 按钮在设定框超界时禁用 |
| AUX 参数超界 | 对应参数框标红，启动按钮禁用，旁边显示「无法启动：{参数} 超出安全边界」 |
| AUX 运行中钳位 | 状态栏黄字「运行中已钳位 N 次」，本次运行只弹一次提示 |
| 辅助功能运行中 | Tab 标题加 ●；同一时刻只能运行一个；手动设定、快速设定、预设选择禁用（完整表见 [详细设计.md](详细设计.md#25-状态--控件可用性)） |
| 命令失败 | 设定框恢复上次确认值 + toast「设定未生效：原因」；ON 失败按钮保持 OFF；OFF 失败显示「未知」红色 + 横幅 |
| 远程控制中 | HTTP 接口开启时状态栏常驻「远程控制中」（蓝） |
| 错误 | 底部 toast + 状态栏红字，可点击查看详情 |

## 7. 中英文
- 中文为默认，系统语言非中文时默认英文，可在图形设置切换，或启动参数 `--english`。
- 字符串表集中在 `i18n.rs`；内置中文字体子集（更纱黑体或思源黑体，附 OFL），用 `FontDefinitions` 注册为 Proportional 与 Monospace 回退。
