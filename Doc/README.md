# IOT_Power 上位机

基于 **Rust + egui/eframe** 的跨平台桌面上位机，用于控制 **DC3005U** 可编程电源 / 功耗分析仪：实时读取电压、电流、功率，绘制曲线、录制 CSV，设定输出并提供预设、序列、扫描等辅助功能。界面参考开源项目 [pd_pocket_pc_controller](https://github.com/ElluIFX/pd_pocket_pc_controller)，通信遵循 [协议文档](Communication/协议文档.md)。

> 状态：文档阶段（0.1.0），代码未开始。

## 特性
- USB 直连（WinUSB / libusb Bulk，VID `0x0408` PID `0x1043`），无需串口驱动
- 实时显示电压 / 电流（自动量程 A/mA/µA，分辨率 10 nA）/ 功率，以及上位机计算的能量、平均功率、负载阻值
- 每条命令读应答确认，失败自动回滚界面状态；断线自动重连，重连不关输出、录制不中断
- 设定电压 **0.8 ~ 24 V**（1 mV）、限流 **0.5 ~ 5.0 A**（1 mA），可在硬件极限内自定义安全边界，超出边界的设定值拒绝下发；首次连接自动关输出
- 双曲线、区间回看、最大/最小/平均统计，CSV 录制与导出
- txt 采集日志（含事件、自动分文件、进程崩溃最多丢 1 s、断电最多丢 5 s），分析窗口回放、区间统计（RMS、Wh、mAh）、导出
- 预设组、序列执行、功率闭环、直流扫描、函数发生器、电池模拟（上位机循环下发设定实现）
- 暗色 / 亮色主题，中文 / 英文界面，单文件可执行
- 可选（P2）：本地 HTTP 接口（默认关闭），供脚本或 AI 调用

## 支持平台
| 平台 | 状态 | 说明 |
|---|---|---|
| Windows 10/11 x64 | 主要目标 | 设备使用 WinUSB 驱动 |
| Linux x86_64（Ubuntu 22.04+） | 主要目标 | 需 udev 规则 |
| macOS | 未验证 | 理论可编译（libusb），不在首发范围 |

## 快速开始
```bash
# 依赖：Rust stable（rustup）；Linux 另需 pkg-config、libudev-dev（默认 nusb 无需 libusb；改用备选 rusb 时再装 libusb-1.0-0-dev）
git clone <仓库地址> && cd IOT_Power
cargo run --release
```
Linux 首次使用需安装 udev 规则，见 [构建发布流程.md](构建发布流程.md#3-linux-udev-规则)。使用前请关闭官方「IoT Power」软件（设备同一时刻只能被一个程序占用）。
