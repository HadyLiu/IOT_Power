# IOT_Power 上位机 产品需求文档（PRD）

> 版本 0.1.0 · 2026-10-10 · 通信依据 [Communication/协议文档.md](Communication/协议文档.md) v0.4 · 界面依据 [界面设计.md](界面设计.md) · 逐控件对照与算法见 [详细设计.md](详细设计.md)

## 1. 背景
DC3005U 是一台 USB 可编程电源 / 功耗分析仪，官方软件「IoT Power 功耗分析仪 v1.3.8」仅支持 Windows、功能固定、无法脚本化。我们已通过抓包得到其 WinUSB Bulk 协议（`55|cmd|params|AA|CRC32`），因此用 Rust + egui 自研一个跨平台、轻量、可扩展的上位机。界面与功能组织参考开源的 PD Pocket 上位机（pd_pocket_pc_controller，The Unlicense）。

## 2. 目标用户
- 嵌入式 / 硬件工程师：给被测板供电、看功耗曲线、记录数据。
- IoT 开发者：测量低功耗设备电流（mA～µA 级，分辨率 10 nA）、做长时间功耗录制。
- 自动化测试：通过序列 / 扫描 /（P2）HTTP 接口做简单批量测试，用 txt 采集日志做事后分析。

## 3. 产品目标
1. Windows 与 Linux 双平台可用，单文件启动 < 1 s，空闲内存 < 80 MB。
2. 覆盖官方软件核心能力：连接、读数、设定、开关、曲线、录制。
3. 在上位机侧补充辅助功能（预设、序列、闭环、扫描等），不依赖新增设备命令。

## 4. 功能列表
优先级：P0 = M1 必须；P1 = M2/M3；P2 = M4 及以后。“协议映射”列只使用协议文档已有命令。

F17 定为 P1 而非 P0：它依赖 M2 的采样管线与数据线程的录制功能（与 F05 共用），M1 的目标是先把连接、读数、设定、安全边界做稳；但它是长时间功耗测试的核心交付物，所以排在 M2 与录制同时上线，分析窗口随 M3。

| 编号 | 功能 | 说明 | 协议映射 | 优先级 | 里程碑 |
|---|---|---|---|---|---|
| F01 | 设备连接 | 按 VID 0408/PID 1043 打开设备、claim 接口 0、发送 `0x01` 握手并解析型号/序列号/固件版本（序列号与上次 `device_serial` 不同时提示；不支持多台设备选择）；断开即 release；断线自动重连（重连不关输出、录制继续）；每条命令读应答确认（[架构设计 §4.1](架构设计.md#41-命令请求-应答规则每条命令都要确认)） | `0x01` | P0 | M1 |
| F02 | 实时读数 | 循环 `0x05`，读 ≈10072 B，解析电压/电流/功率/帧序号/设定回显；状态区显示 V、I（自动量程 A/mA/µA）、P（主机计算 V×I）及上位机计算的能量、平均功率、负载阻值（断线时段不计入能量）；回零 | `0x05` | P0 | M1 |
| F03 | 输出设定与开关 | 设定电压与限流（输出电流上限；`0x03` 电压 mV + 限流 mA，分辨率 1 mV/1 mA），必须在安全边界（F16）内，超界标红拒绝、不下发；用 @52/@54 回显确认设定生效，失败回滚；首次连接自动关输出（重连不关）；设定框区分「编辑值」与「设备设定」，编辑值未提交前不会被回显覆盖；快速设定；输出 ON/OFF（ON 前若编辑值与设备设定不同，先下发 `0x03` 并等回显确认，再发 `0x06 01`）；进度条；输出开启警告、输出时锁定参数 | `0x03`、`0x06` | P0 | M1 |
| F04 | 数据曲线 | 双曲线（电压/电流/功率/阻值/无），采样间隔（即 `0x05` 轮询间隔，默认 50 ms，下限 50 ms，实测后再调）可调并显示实际采样率；适应/保持/清空；区间滑块与统计 | — | P1 | M2 |
| F05 | 录制与导出 | CSV 录制（兼容原版列，每 30 s 落盘，可在设置中关闭）、导出缓冲区；与 F17 txt 日志同一次录制同时生成 | — | P1 | M2 |
| F06 | 预设组 | 9 组 电压/限流 预设，选中即下发 | `0x03` | P1 | M3 |
| F07 | 序列执行 | DELAY / WAIT / SET-V / SET-I 序列，单次/循环，txt 保存载入 | `0x03`、`0x06` | P1 | M3 |
| F08 | 设置与持久化 | 电源设置、图形设置（主题、刷新率、插值、置零阈值、显示修正 y=kx+b），`settings.json` 持久化 | — | P0（基础）/P1（图形） | M1/M3 |
| F09 | 悬浮窗 | 置顶小窗显示 U/I/P | — | P1 | M3 |
| F10 | 功率闭环 | 积分控制（原版 Kp=0、Kd=0）调节 Vset，使实测功率跟踪目标 | 循环 `0x03` | P2 | M4 |
| F11 | 直流扫描 | 按步进扫描电压或电流并记录响应，结果窗口 | 循环 `0x03` | P2 | M4 |
| F12 | 函数发生器 | 方波/正弦/三角/锯齿/噪声写入 Vset（受 USB 往返延迟限制，频率低） | 循环 `0x03` | P2 | M4 |
| F13 | 电池模拟 | 按 SOC-OCV 曲线与内阻计算 Vset | 循环 `0x03`、`0x06` | P2 | M4 |
| F14 | 本地 HTTP 接口 | 默认关闭；仅监听 127.0.0.1、带 token，供脚本/AI 读数与设定；开启后状态栏显示「远程控制中」；远程开输出需单独勾选「允许远程打开输出」（默认不勾），不弹确认框，受安全边界、输出锁定、AUX 互斥约束 | 复用 F02/F03 | P2 | M4 之后 |
| F15 | 多语言 | 中文（默认）/英文 | — | P1 | M3 |
| F16 | 安全边界与输入校验 | 硬件极限 0.8~24 V / 0.5~5.0 A 固定；用户在硬件极限内设电压/电流上下限（默认等于硬件极限，下限 ≤ 上限，不合法标红并说明原因、不保存，只能在输出关闭时修改）。所有设定来源（手动、快速设定、预设、序列、扫描/闭环/函数发生器/电池模拟参数及其运行中在线修改、HTTP）按安全边界校验，超界拒绝并提示（HTTP 返回 400）；仅高级功能运行中的瞬时值钳位并告警；IO 线程兜底钳位记日志 | `0x03` | P0 | M1 |
| F17 | txt 采集日志与记录分析 | 录制时同时写 txt 采集日志（文件头注释 + 制表符分隔数据行 + 事件行：设定变更、开关、断线重连、命令失败），按时长/大小自动分文件，1 s 写盘、崩溃最多丢 1 s；分析窗口载入 txt 回放浏览、区间选择、统计（最大/最小/平均/RMS、能量 Wh、容量 mAh、时长）、事件标注、导出 CSV；多文件对比为 P2。格式见 [详细设计 §3.7](详细设计.md#37-txt-采集日志f17) | — | P1（多文件对比 P2） | M2（日志）/M3（分析窗口） |

### 4.1 已移除（设备无此功能）
原 PD Pocket 上位机的以下 7 项功能，经确认 DC3005U 设备本身没有，已从产品中移除，不分配 F 编号、不做界面：最大输出功率、输出校准、输入校准、短路保护、按键锁、CV/CC 状态、输入电压。

## 5. 非功能需求
| 类别 | 要求 |
|---|---|
| 平台 | Windows 10/11 x64（WinUSB）、Ubuntu 22.04+ x86_64（libusb + udev） |
| 性能 | 默认轮询间隔 50 ms（20 Hz）稳定运行；轮询下限实测前定为 50 ms（每帧约 10 KB，USB 全速 Bulk 下约 200 KB/s）；曲线 10 万点下 ≥ 30 fps；空闲 CPU < 5% |
| 资源 | 单文件可执行 < 20 MB（含中文字体子集）；内存 < 150 MB（默认 10 万点缓冲）；记录点数上限 100 万点（缓冲约 48 MB） |
| 可靠性 | 拔插、设备被占用、超时均不崩溃；自动重连且录制不中断；IO、AUX、UI 线程隔离，窗口最小化不影响 AUX 与录制；txt 日志进程崩溃最多丢 1 s、断电最多丢 5 s 数据 |
| 安全 | 设定值超出安全边界一律拒绝（不静默钳位），IO 线程按安全边界与硬件极限兜底；首次连接自动关输出，重连不关；每条命令读应答，失败回滚界面状态；可选开输出前确认；HTTP 默认关闭、仅本机 + token，远程开输出需单独授权 |
| 可用性 | 中文字体内置，开箱可显示中文；错误提示给出明确操作（如“请关闭官方 IoT Power 软件”） |
| 可维护性 | 协议编解码为纯函数并有单元测试（含协议文档中的 CRC 示例帧） |

## 6. 里程碑
| 里程碑 | 内容 | 功能编号 |
|---|---|---|
| M1 连接 + 读数 | USB 连接、握手、命令应答确认、轮询解析、状态区（含能量/平均功率/阻值与回零）、设定与开关（含输出开启警告、输出时锁定）、安全边界、基础设置持久化、中文字体 | F01 F02 F03 F08(基础) F16 |
| M2 曲线 + 记录 | 双曲线、轮询间隔调节、区间回看与统计、CSV 录制/导出、txt 采集日志 | F04 F05 F17(日志) |
| M3 设置 / 控制 | 图形设置、预设组、序列、悬浮窗、中英双语、记录分析窗口 | F06 F07 F08(图形) F09 F15 F17(分析) |
| M4 高级功能 | 功率闭环、直流扫描、函数发生器、电池模拟 | F10 F11 F12 F13 |

## 7. 范围外
- 固件升级（`.up` 文件）。
- 10072 字节读数帧中采样/波形区的解析（协议未标定，待确认后再做高速波形显示）。
- macOS、移动端、网页版。
- 多设备同时连接。

## 8. 待确认
本节是全部文档唯一的待确认清单（架构设计、详细设计、测试用例只链接到这里）。

| # | 事项 | 影响 | 当前处理 |
|---|---|---|---|
| 1 | 设备可承受的最小 `0x05` 轮询间隔与最小 `0x03` 连续下发间隔 | F02/F04、F10~F13 执行频率 | 轮询下限与默认都定 50 ms；`0x03` 最小间隔 100 ms；实测后调整 |
| 2 | `0x01`/`0x03`/`0x06` 短应答的长度与内容（是否带状态码）；各命令实际往返时间 | 应答校验、超时默认值 | 收到非空应答即算已应答；超时 300/500 ms；实测后加严 |
| 3 | 读数帧偏移 32–51 能否回读输出开关状态 | ON/OFF 是否能经设备确认 | 以最后一次已应答的 `0x06` 为准，标注「状态未经设备确认」 |
| 4 | 断线或主机程序崩溃后设备是否保持输出；有无通信超时自动关输出 | 断线/崩溃安全 | 按「保持输出」最坏情况设计（横幅提示、panic hook 尽力关输出） |
| 5 | 在设备面板上手动改设定后，@52/@54 回显是否同步变化 | 设定同步 | 回显与「设备设定」不一致且无待确认命令时，以回显更新设备设定并记事件；设定框编辑值未提交时不覆盖，只提示（[详细设计 §2.6](详细设计.md#26-设定值模型编辑值与设备设定)） |
| 6 | 设备实际输出步进是否真达到 1 mV / 1 mA | 扫描步进下限、按位更改最小位 | 按 1 mV / 1 mA 设计，扫描步进下限 0.001 |
| 7 | `0x06` 与官方 UI 按钮的对应关系 | 文案 | 语义按输出开关处理 |
| 8 | `nusb` 在 Windows WinUSB 下的稳定性 | 传输层选型 | 首选 nusb，备选 rusb |
| 9 | 读数帧 56 字节之后约 10 KB 采样/波形区格式 | 高速波形（范围外） | 不解析 |
| 10 | 设备内部读数帧的更新周期（决定同一序号会不会被连续读到） | 重复帧判定、实际可用采样率 | 序号重复按重复帧丢弃（[架构设计 §4.1](架构设计.md#41-命令请求-应答规则每条命令都要确认)），实测后再定轮询下限 |
| 11 | 用 Zadig 装 WinUSB 是否影响官方软件；安装包是否附 Zadig 说明 | Windows 驱动说明 | 不随包装驱动，用户手册只写设备管理器排查 |
| 12 | 项目许可证 | 发布、README | 待定；发布前必须确定 |
| 13 | 仓库地址 | CHANGELOG 链接、发布命令 | 待定 |

已确定：设定换算（协议 v0.4：电压 mV、限流 mA，1 mV/1 mA）；读数帧 u32@20 电流是**瞬时值**（用户 2026-10-10 确认），所以 50 ms 轮询会漏掉更短的电流脉冲，能量/mAh 是按采样点估算的值，用户手册已注明；首次连接自动关输出、重连不关；电流置零阈值默认 0；状态区功率用主机 V×I（设备功率字段最大 42.95 W，仅调试）；安全边界 F16；txt 采集日志 F17；HTTP 默认关闭且远程开输出需单独授权；轮询下限 50 ms；设定值模型（编辑值/设备设定）、ON 前先确认设定、输出状态三级显示（已应答/未经确认/未知）、AUX 独立线程、Esc 只在 AUX 运行时急停等第二轮决定见 [CHANGELOG](CHANGELOG.md)。
